## Gameplay Loop

Move on the beat, collect keys to unlock doors, and chain movement patterns into element-based attacks to clear enemies and escape each room.

## Core Features

- Control the character on the beat!
- Step on coloured tiles to start attacks!
- Different sequences of moves trigger different attacks!
- Destroy all the blockades and defeat the enemies to escape from the Lab!

## Controls

- W/A/S/D -> Move Up/Left/Down/Right
- Pause -> esc

## Play Locally (Unity)

1. Install Unity Editor `6000.2.8f1` (or newer `6000.2.x`) via Unity Hub.
2. Clone this repository.
3. Open the project folder in Unity Hub.
4. Wait for package import/compilation to finish.
5. Open `Assets/Scenes/Init.unity` (recommended) or `Assets/Scenes/MainMenu.unity`.
6. Press Play in the Unity Editor.

## Scene Flow

- `Init` -> `MainMenu` -> `Tutorial 1-4` -> `Level 1-2`
